# Checklist de qualidade antes de uma release

- [ ] Conferir títulos, descriptions, canonical e indexabilidade das páginas.
- [ ] Validar links internos e HTTP 200/301/404 conforme a intenção.
- [ ] Inspecionar sitemap.xml e robots.txt em produção.
- [ ] Validar dados estruturados com ferramentas apropriadas.
- [ ] Testar navegação por teclado, foco, contraste e nomes acessíveis.
- [ ] Verificar console do navegador e erros de rede.
- [ ] Medir Core Web Vitals com dados de campo quando disponíveis.
- [ ] Conferir imagens responsivas e atributos alt.
- [ ] Revisar tratamento de consentimento e privacidade.
- [ ] Confirmar ausência de credenciais e dados não autorizados.

**Observação:** checklist metodológico, não evidência de execução.
